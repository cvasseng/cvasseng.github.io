How sending works
Reading the key
Every key-down and key-up edge is timed, thresholded into dits and dahs against your keying speed, and decoded with the same character table the receiving side uses. Farnsworth does not apply: it stretches gaps for a listener, so sending is measured against standard spacing at whatever speed the dial says.
Key type
Straight key, iambic A or iambic B, in Settings. The two iambic modes differ in exactly one rule: release a squeeze during an element and mode B sends one more to finish the alternation, where mode A stops.
Fist quality
Weight ratio, spacing and consistency, in dit units rather than milliseconds so two speeds are comparable. In the summary after every straight key session, and broken down by keying speed under Stats, which is where you see what falls apart as you speed up. A keyer gets no fist report, because its timing is the keyer's and not yours.
Scoring
Compared against the target with the same alignment the copy screen uses, and recorded in its own namespace: nothing you key can move a receiving figure, and sending never unlocks a character.

What it deliberately does not do

Pretend the tone is not late
The sidetone toggle sits beside the keying speed in Sending setup, and is on by default. A browser is late by its audio output buffer plus whatever the operating system adds, so if your key or adapter makes its own tone, turn this off and use that one: it will be tighter than anything a browser can do.
Use WebHID or Web Serial
Both would give better timestamps than keyboard emulation, and both are Chromium only. Keyboard emulation is the portable path and works in Firefox, which clamps timers to 1 ms: ample, since a dit at 20 wpm is 60 ms.

Speed

Farnsworth: characters stay fast, the gaps stretch. Clamped to the character speed.

The same pair is in Drill setup on the Copy screen, so easing the gap and going again does not cross a screen. These sliders and that dial are one setting: change either and both follow.

Audio

Hard-gating a sine wave clicks. This softens each edge.

Band conditions (noise, fading, a second station) are in Drill setup on the Copy screen. They are recorded with every attempt, and speed advice only ever compares like with like.

Sending

Set once, for whatever is plugged in. A straight key is one contact: Space, or an adapter's Ctrl. A paddle is two: left Ctrl and right Ctrl, or Z and X if you have no hardware yet. The keying speed itself is in Sending setup, since that is a dial you reach for mid-practice.

Modes A and B differ in exactly one rule. Release a squeeze during an element and mode B sends one more, completing the alternation; mode A stops at the element it was sending. Whichever you learned on will feel like the right one.

What this is

A Morse trainer for both halves of the skill: copying what you hear, and keying it back. One drill engine, seven kinds of content, and statistics that try hard not to flatter you.

It runs entirely in this browser. There is no account, no server and nothing is uploaded, which also means exporting your progress is the only backup that exists. Clearing site data deletes all of it.

The character reference has the whole table, with every character audible.
